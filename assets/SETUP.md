# Assets Setup Instructions

## 📸 Adding the SignalScope Poster

To complete the README setup, you need to add the poster image to this folder.

### Steps:

1. **Download the poster** from Google Drive:
   - Link: https://drive.google.com/file/d/1yJ33enRmr7QNFd_cwelGD9wn7OvehpgG/view?usp=drive_link
   - Or use the poster image from your project files

2. **Save the image** in this `assets/` folder as:
   ```
   signalscope-poster.jpg
   ```

3. **Verify** the README displays correctly on GitHub

### Alternative: Use Direct Link

If you prefer not to store the image in the repository, the README will fall back to displaying a link to the Google Drive video/poster.
